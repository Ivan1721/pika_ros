# **<font style="color:#1a1a1a;">1.</font>****<font style="color:#1a1a1a;">Introducción del Producto</font>**
## **<font style="color:#1a1a1a;">1.1 </font>****<font style="color:#1a1a1a;">Descripción General</font>**
<font style="color:#333333;">El kit de datos Pika (en adelante, Pika) es un </font>**<font style="color:#333333;">producto de recolección de datos espaciales</font>**<font style="color:#333333;"> orientado a la </font>**<font style="color:#333333;">inteligencia corporeizada</font>**<font style="color:#333333;"> (embodied intelligence). Es una solución portátil e integrada de captura y ejecución para operaciones generales, compuesta por un dispositivo de recolección, un </font><font style="color:#333333;">ejecutor de inferencia de modelos</font><font style="color:#333333;"> y una estación base de posicionamiento y mochila de datos.</font><font style="color:#333333;"> Permite recolectar</font><font style="color:#333333;"> de forma eficiente, precisa, ágil y ligera datos de operación espacial de robots.</font>

<font style="color:#333333;">Pika</font><font style="color:#333333;"> posee una</font><font style="color:#333333;"> capacidad de recolección de información espacial de </font>**<font style="color:#333333;">precisión milimétrica</font>**<font style="color:#333333;">,</font><font style="color:#333333;"> soportando la recolección de</font><font style="color:#333333;"> datos que abarcan información espacial precisa de seis grados de libertad, información de profundidad, información visual de gran angular</font><font style="color:#333333;"> </font><font style="color:#333333;">y datos de agarre. Satisface la</font>**<font style="color:#333333;"> necesidad de fusión de múltiples fuentes de datos</font>**<font style="color:#333333;"> en el campo de la inteligencia corporeizada. El</font><font style="color:#333333;"> efector</font><font style="color:#333333;"> puede usar los datos recolectados por el</font><font style="color:#333333;"> recolector (Pika Sense)</font><font style="color:#333333;"> para inferencia de modelos.</font>

<font style="color:#333333;">Pika está compuesto por la unidad portátil de recolección de datos (Pika Sense), el efector final (Pika Gripper), la estación base de posicionamiento (Pika Station) y la mochila de datos portátil (Pika Package), como se muestra a continuación. Pika Sense y Pika Station pueden usarse con Pika Package o laptop para recolección de datos; Pika Gripper puede usarse de forma independiente para ejecución de inferencia; Pika Sense + Pika Station + Pika Gripper + laptop permiten la recolección de datos por teleoperación.</font>

## **<font style="color:#1a1a1a;">1.6 Descripción de módulos</font>**
<font style="color:#333333;">El producto completo Pika incluye el recolector de datos Pika (Pika Sense), la unidad ejecutora Pika (Pika Gripper), la estación base de posicionamiento de alta precisión (Pika Station) y la mochila de datos (Pika Package). El Pika Sense está compuesto por un operador portátil, cámara de profundidad de alta precisión, cámara monofocal gran angular, encoder de alta precisión y pinza de dos dedos. El Pika Gripper está compuesto por </font><font style="color:#333333;">pinza de dos dedos, cámara de profundidad, cámara gran angular y motor brushless de alta precisión. El sistema de estación base de posicionamiento de alta precisión incluye soporte móvil y batería para lograr posicionamiento milimétrico de los dispositivos Pika en el espacio.</font>
